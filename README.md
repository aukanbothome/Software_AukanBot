## Overview

A modular robotic system developed for RoboCup competitions, focused on human–robot interaction, safe navigation, and real hardware control.

The project is designed with a clear, responsibility-separated architecture, where a Raspberry Pi acts as the central brain and multiple ESP32 boards control the robot’s actuators.
